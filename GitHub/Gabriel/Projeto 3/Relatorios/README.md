# Projeto 3 - Módulo de Relatórios

Gerador de relatórios analíticos, executivos e consolidação de indicadores (KPIs).

## Funcionalidades
- Emissão de relatórios em formato JSON/Tabela
- Consolidação de métricas por empresa e centro de custos
- Exportação de dados para auditoria

## Execução
```bash
node src/index.js
```
