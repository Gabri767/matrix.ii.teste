# Projeto 1 - Módulo de Empresas

Sistema de cadastro e gestão de dados empresariais, filiais e parceiros.

## Funcionalidades
- Cadastro de empresas (CNPJ, Razão Social, Nome Fantasia)
- Gestão de filiais e unidades
- Integração com módulo contábil e emissão de relatórios

## Execução
```bash
node src/index.js
```
